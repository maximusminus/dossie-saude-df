# dossie-saude-df

O site publicado: <https://maximusminus.github.io/dossie-saude-df/>

**Este repositório é gerado.** Cada arquivo aqui é escrito por
`scripts_extracao/site.py` no repositório de trabalho, a partir das
mesmas fontes que o build confere a cada execução. Nada é editado à
mão, e uma edição manual é desfeita na publicação seguinte.

O que está aqui:

- o dossiê e seus três anexos (procedência, lacunas, sumário executivo);
- as 66 tabelas de que as afirmações publicadas são lidas,
  mais as tabelas de cobertura e de lacuna;
- as notas de método, em inglês.

Nenhuma linha publicada aqui identifica uma pessoa. Os agregados de
folha são `(ano, mês, cargo)` e o gerador falha antes de publicar
qualquer coluna fora disso.
