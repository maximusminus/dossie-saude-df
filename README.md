# dossie-saude-df

O site publicado: <https://maximusminus.github.io/dossie-saude-df/>

**Este repositório é gerado.** Cada arquivo aqui é escrito a partir
das mesmas fontes que conferem o texto a cada execução. Nada é editado
à mão, e uma edição manual é desfeita na publicação seguinte.

O que está aqui:

- o painel de dados, com exportação em cada visão;
- o dossiê e o sumário executivo, em texto e em PDF;
- as 66 tabelas de que as afirmações publicadas são lidas,
  mais as tabelas de cobertura e de lacuna;
- as notas de método.

Nenhuma linha publicada aqui identifica uma pessoa. Os agregados de
folha são `(ano, mês, cargo)` e o gerador falha antes de publicar
qualquer coluna fora disso.
